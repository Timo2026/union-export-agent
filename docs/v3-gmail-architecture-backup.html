四 Pillar 明细 NEW

P1Gmail 接入

GitHub 库 imap_tools（Apache-2.0）。UI 设置页填 Gmail App Password，默认禁用，显式开关后才 sync。

新增：services/gmail_imap.py · services/credentials.py · API /v1/gmail/*

降级：未启用时仍走本地 .eml 上传 / mailbox 目录。

P2V12 内核仪表板

新 tab #tab-v12：展示 Timo_CNC-AI-Brain v12.0-Fusion 在线状态、报价吞吐、C1–C6 DFM、sha256 审计链。

新增：services/v12_status.py · API /v1/v12/*

数据源：既有 adapters/timo_adapter.py + audit 文件，不新建内核。

P3流程管理 · HITL 面板

在 mailbox 侧栏 verification 区内嵌审批 UI：批准 → /v1/rfq/{cid}/approve；打回 → 备注入库。

铁律①可视化：报价旁 🔒 + sha256；试图改数字 → 红字拦截（OpenShell）。

不做：邮件独立状态机 / Kanban（与 RFQ 状态机冲突）。

P4上下文联动

侧栏卡片双向跳转：Mail.openContext(cid) — 待审→HITL 面板；历史 RFQ→对应 context；几何→对应 commercial。

mailDetail 顶部面包屑：📧 邮件 · 材料×数量 · DFM · quote · HITL 状态。

纯前端增量，不改 8 区 API 契约。
