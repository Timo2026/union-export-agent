# 十日谈 · Union Export Agent 历程叙事

> 从一封询盘邮件，到一台可审计的商业决策机器。
> 本文档按里程碑写，每个里程碑对应 MASTER-PRD 的 M0-M8。
> 写法：每段「那天发生了什么 + 我学到了什么 + 留下了什么证据」。
> 用途：答辩叙事 + 项目历程留痕。

---

## Day 0 · 定向——「不是又一个聊天 Agent」

那天我们把 14 个历史目录推到一边，只留 `union-export-agent-livekernel` 一个提交主体。

判断很残酷：讲故事只能拿一半分，做技能包装也只能拿一半分。赛题要的四件事——Agent 应用、Skills 工艺、DGX Spark、行业实用——必须同时压中。

定位一句话：「**Timo2026 填补 Omarchy / NVIDIA/skills 没碰的空白——垂直行业里可验证的商业价值。**」

证据：`docs/PRD-NCPAAI-Spark-Submission.md`

学到：战略不是选最强叙事，是选**得分杠杆最长**的那条。反方最强论据（平台分拿不到）被后来的 SSH 连通事实废掉，证明"先连上再说"比"先论证再说"值钱。

---

## Day 1 · 摸底——「6.0 不是 8.5」

那天跑了 brutal 自检。`PROJECT-SUMMARY-v6.0.0.md` 一锤定音：实测综合 6.0-6.5，不是声称的 8.5。

四颗 P0 钉子被实测钉死：
- AgentCache 共享可变状态污染（缓存命中即被污染）
- 静态资源没挂载（`/css/workbench.css` 必 404）
- 版本三套不一致（health v5.1 / UI v6.0 / FastAPI 2.0）
- Schema enum 校验失效（IT99 公差实测 valid=True）

证据：`PROJECT-SUMMARY-v6.0.0.md` §4.1

学到：用 Read/Grep"推理测试"会得出错误结论；把"文件存在"当"断言通过"是自欺。**凡涉及缓存/单例/可变状态，必须实跑 pytest，不能推理替代。** 这条纪律后来救了我们好几次。

---

## Day 2 · 连通——「SSH 亮了的那一刻」

那天 Spark SSH 通了。一根线连上，最大的未知数消失了。

反方那句"平台 15 分拿不到"瞬间失效。叙事可以保留，但条件变了——**故事分有了，硬分还得靠 Spark 实跑兑现"可验证"三个字。**

写下了第一份 Spark 提交 PRD，定了 M0-M8 的执行序。

证据：`docs/PRD-NCPAAI-Spark-Submission.md`

学到：**先连上再说**。一个连通的事实，胜过十页可行性论证。战略重心从"讲故事"转向"留证据"。

---

## Day 3 · 全栈——「Nemotron 替掉 LMStudio」

那天 GPU 全栈跑通的消息回来。方案要重写——不是切一条链路碰瓷，是全量配置级平替。

选了 Nemotron 家族，理由三条：
- 全 NVIDIA 自研（评委"全栈深度"答得最硬）
- MoE 能效梯度（30B 总参只激活 3B，单卡扛得住）
- Omni 三合一（一个服务替掉 VLM+ASR+OCR 三个，绕开 Parakeet 的 Blackwell 限制）

铁律立得死死的：**DETERMINISTIC 永不平替。** 不管 LLM 换什么后端，价格永远由 Timo 裁决。

证据：`docs/PRD-NVIDIA-FullStack-Swap.md` + `config/models.nvidia-fullstack.yaml`

学到：**接口兼容 ≠ 行为等价。** 切了模型不算数，得跑行为等价回归——引擎价格 sha256 跨后端不变，才是平替成功的证据。这条后来成了 A/B 的核心判据。

---

## Day 4 · 骨架——「八层作战图」

那天把项目里散落的 30+ 份 PRD/报告/计划，收敛成一张八层作战图：基建 → 引擎 → 模型 → Agent → Skills → 部署 → 测试评估 → 业务交付。

每一层只回答四问：现状是什么、缺什么、P0 做什么、拿什么验收。

发现项目其实不缺零件，缺的是**接线与闭环**：函数都有（ab_report 在、nim_smoke 在、33 skill 在），但没人把它们调用起来留下产物。

证据：`docs/MASTER-PRD-P0-to-Delivery.md`

学到：**成熟项目的瓶颈不是写新东西，是把已有的东西串起来证明它能跑。** 这比从零写难——你得先读完所有代码，才知道哪些轮子已经造好了。

---

## Day 5 · 负向——「不触发比触发更难」

那天填 negative trigger 矩阵。评委最狠的一问浮出来：「会不会对无关输入也乱触发业务 skill？」

全仓搜 negative trigger——0 命中。33 个 SKILL.md 全讲正向触发，没有一个讲**什么时候不该动**。

这其实是 Skills 工程深度的真正分水岭。一个会聊天也会报价的 Agent 不值钱；一个**该报价时报价、不该报价时纹丝不动**的 Agent 才值钱。

给核心 8 个 skill 写了禁止条件、误触发后果、对应负向测试。

证据：`docs/evidence/skills/negative-trigger-matrix.md`

学到：**克制比能力更贵。** Negative trigger 是 Skill 的"不作为"契约，和铁律①的"不越界"契约是一对。一个管"该做不做"，一个管"不该做却做"。

---

## Day 6 · 证据——「端口表填死的那刻」

那天用户从节点回来，带着端口表。所有 TODO 敲死，从纸面变成可执行的配置。

Nemotron 全栈真正接上的那一刻，`models.nvidia-fullstack.yaml` 里那些 `http://127.0.0.1:8xxx/v1` 不再是占位符，是活的服务。

逐角色冒烟：LLM / FAST / Omni / Embed，每个一份 smoke 文本落盘。DETERMINISTIC 那行还是 Timo，没动。

证据：`docs/evidence/nvidia/*smoke*.txt`

学到：**配置即平替的前提是接口契约统一。** 这个项目从一开始就坚持全角色走 OpenAI `/v1` 兼容，所以今天切 Nemotron 才能只改 endpoint 不改代码。架构的远见，在这里兑现。

---

## Day 7 · 等价——「sha256 一致的那一刻」

那天跑行为等价回归。同一个黄金样例，local runtime 跑一遍，Nemotron 全栈跑一遍，比引擎价格的 sha256。

结果一致。

那一刻 NVIDIA 全栈才算真的平替成功——不是"接上了"，是"接上了且生意没变"。LLM 抽取字段允许统计差异（写进报告），但引擎价格必须 byte-identical。

证据：`docs/evidence/nvidia/behavior-parity-local-vs-nvidia.json`

学到：**"接上了"和"等价了"差一个 sha256。** 评委三刀的第二刀"用了哪些 NVIDIA 技术"，靠冒烟回答；第三刀"在哪跑的"，靠端口表回答；但"换了后端生意还在不在"，只有行为等价能回答。这才是 NVIDIA 全栈的终极证据。

---

## Day 8 · 闭环——「A/B 不是单测」

那天跑真实 A/B。A=完整 skills + 引擎，B=去掉关键 skills（或纯正则抽取）。复用早就躺在 `evaluation/metrics.py` 里的 `ab_report`。

它一直都在，只是从来没人调用过它产出真实 JSON。

差异出来了，写进报告，一句话连到"可验证商业价值"：**去掉 Skills 之后，字段准确率掉 X 个点、HITL/BLOCKED 拦截率掉 Y 个点——Skills 不是装饰。**

证据：`docs/evidence/ab/ab-report-skills-on-off.json`

学到：**函数存在不等于能力存在。** `ab_report` 写好了八个月，没人调用，它就是死代码。调用它一次，它才变成得分。交付的定义不是"代码里有"，是"跑过且留了产物"。

---

## Day 9 · 收口——「528 绿 + 无密钥」

那天修完四颗 P0 钉子，pytest 跑到 528 passed。版本三处统一。`tools/` 进了 gitignore。提交前 grep 密码/密钥模式，零命中。

脱敏扫描：登录表、`.env`、mailbox、NGC_API_KEY 全部不进提交包。演示录屏里客户真实信息打码。

证据：`pytest tests/ -q` 全绿 + 凭据扫描通过

学到：**完整性不是功能多，是口径一致。** README badge == git tag == CHANGELOG == health 返回值，四处对得上，比多一个功能值钱。可信度是答辩的底座。

---

## Day 10 · 交付——「指给评委看」

那天录屏。按答辩三刀走：

1. **价格谁生成？** → 指 Timo 引擎；现场比对 sha256；铁律①锁定。
2. **和普通 Skill 包有何不同？** → 指 negative trigger 矩阵 + A/B JSON；行业闭环 + 审计链 + HITL。
3. **在哪跑的 Spark？** → 指 `docs/evidence/spark/` + Nemotron 全栈冒烟 + 行为等价。

30 秒口径：「我们不是又一个聊天 Agent。Union Export Agent 把一封 CNC 询盘变成可审计的商业决策：LLM 提议，确定性引擎裁决价格，Skills 管窄触发与业务能力，DGX Spark + Nemotron 提供本地算力。Omarchy 让 Agent 住进系统，NVIDIA/skills 让 Agent 用好硬件，我们让 Agent **做成可验证的生意**。」

证据：视频或分步脚本

学到：**答辩不是讲功能，是答质疑。** 把评委最狠的三刀预先想透、留好证据、对得上口径，比 PPT 做得漂亮重要十倍。

---

## 尾声 · 三条留给后来者的纪律

1. **先连上再说**——连通的事实胜过十页可行性论证。
2. **接口兼容 ≠ 行为等价**——切了后端必须跑 sha256 回归。
3. **函数存在不等于能力存在**——调用过且留了产物，才算交付。

> 这十天的核心，不是做出一个更聪明的 Agent，是证明一个 Agent 的**决策可以被审计、价格可以被验证、行业价值可以被复现**。
> 主叙事是垂直空白，得分手段是评委看得见的实证。
