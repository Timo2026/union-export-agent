UEA-NCPAAI 技术雷达对比

v3.0.1-mailbox（当前） vs v4.0.0-workbench（设计目标） · 2026-09-18

v3.0.1-mailbox 当前

  • 8 Tab 按钮堆叠：邮箱/上传/3D/反馈/技能/邮件台/V12/内核
  • 7 区只读卡片：右栏 region 堆叠，无对话输入
  • 10 个 Skill 已封装，但 无 Chat UI 调用 dispatcher
  • 三栏 无交互联动，右栏不能引用为左邮件批注
  • HITL 深埋 B-9，无全局 banner
  • LLM 离线时 静默降级，用户无感知
  • 0 API 新增，后端完全复用

v4.0.0-workbench 目标

  • 三栏 IA：左 Inbox · 中 Inspector(5 tabs) · 右 Chat + Skill Console
  • 对话驱动：自然语言 → Skill 编排 → Agent 气泡 + Badge + Cite + Trace
  • 17 个 Agent Skills（9 复用 + 8 新增），全部 可 Chat 调用
  • 跨栏全联动：点邮件→中栏加载+右栏 bind；Chat 调用→中栏高亮
  • 铁律可视化：sha16 锁 + 篡改红 banner + 审计尾巴
  • 离线降级显式：角标 🤖 rules_only / MOCK
  • 仅新增 5 API：/chat/turn /history /reset /explain /skills
评分口径：1=缺失/薄弱，5=可用，10=优秀/领先 · 数据源自 PRD-v4-workbench.md §0 痛点核对 & §1-2 设计目标
