## 2. 权重下载（tmux · hf-mirror · ~1.25MB/s · timo_ 前缀）
```
# 真实命令（huggingface_hub CLI，指向镜像端点；本地目录加 timo_ 前缀）
export HF_ENDPOINT=https://hf-mirror.com
# 批次① always-on（16GB ≈ 4h）
hf download nvidia/NVIDIA-Nemotron-3-Nano-4B-BF16 --local-dir ~/models/timo_nano4b            # 8.0GB/18f
hf download nvidia/Nemotron-3-Embed-1B-BF16 --local-dir ~/models/timo_embed1b                   # 2.3GB/15f
hf download nvidia/nemotron-3.5-asr-streaming-0.6b --local-dir ~/models/timo_asr06b             # 5.7GB/22f
# 批次② 按需（44GB ≈ 10h）
hf download nvidia/Nemotron-3-Nano-Omni-30B-A3B-Reasoning-NVFP4 --local-dir ~/models/timo_omni  # 22.4GB/26f (custom_code → trust_remote_code)
hf download nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4 --local-dir ~/models/timo_lightning  # 21.6GB/70f
```
已知否决（禁止回流）：GGUF（无 FP4 tensor core 路径）、NVFP4-DSpark（1.35GB 非自包含）、nv-embedqa（NIM 已废）。
